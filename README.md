## What is this?

An interactive product prototype built for a Senior PM interview at E.ON Next. The brief: *improve the experience of a connected device ecosystem.*

I focused on the **EV activation gap** - customers who install a home charger but never unlock the savings available through E.ON Next's **Next Drive Smart** tariff (8.5p/kWh off-peak vs 30.9p/kWh standard - a confirmed **£117/year** saving).

## 📱 App Prototype

A guided activation wizard and savings dashboard built into the E.ON Next Home app, collapsing 4 fragmented steps into one seamless flow.

**The journey:**

1. 🔔 Install day push notification
2. 🚗 Connect your car (auto-detected via account records, MPAN pre-filled)
3. ✅ Data consent in plain English - savings shown upfront
4. ⚡ Activate Next Drive Smart tariff
5. ⏳ 2-week smart meter wait - progress tracker keeps you engaged
6. 💰 Savings dashboard live - real-time £ saved, weekly charge history, Boost mode

---

## 📊 User Analytics Dashboard

GA4-style PM dashboard to track whether the product is working.

- **Overview** - North Star (38% towards target of 60%), trend chart
- **Activation Funnel** - drop-off analysis at each wizard step
- **Engagement** - DAU/MAU, Alert CTR, Boost mode usage
- **Business Impact** - revenue vs control cohort, churn, support contacts
- **OKRs** - 3 objectives, 9 key results with live progress bars

> 📝 All analytics figures are modelled and illustrative
